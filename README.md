# 추억 공작소 7080 뮤직 바 & 라이브 콘텐츠 플랫폼

단일 HTML 파일로 구성된 웹앱 프로토타입입니다. 사업 기획서의 핵심 내용을 시각적으로 정리하여 이해관계자와 공유할 수 있도록 제작되었습니다.

## 미리보기
- **사업 개요**: 플랫폼 목표, 핵심 가치, 키워드를 카드 형태로 정리
- **비즈니스 모델**: 통합 검색, 예약, 커뮤니티, 엔터테이너 중개 등 주요 기능 소개
- **독점 콘텐츠 전략**: Suno AI 기반 음원 제작과 라이브 공연 영상화 계획 설명
- **주체별 가치**: 고객/가맹점/플랫폼 운영자별 가치와 수익 모델을 탭으로 전환하며 확인
- **로드맵 & 리스크**: 단계별 실행 계획과 AI 저작권 리스크 대응 방안 제시

## 실행 방법
1. 저장소를 클론하거나 ZIP으로 다운로드합니다.
2. `index.html` 파일을 브라우저에서 직접 열면 즉시 확인할 수 있습니다.

## 맞춤 활용 아이디어
- 투자자 또는 파트너 대상 피치 덱의 웹 버전으로 활용
- MVP 및 프로토타입 발표용 랜딩 페이지
- 브랜드 아이덴티티에 맞춘 색상과 카피로 빠르게 커스터마이징 가능
